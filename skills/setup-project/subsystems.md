# Subsystems

A subsystem page is a design reference, not a wish. Before changing a
documented subsystem, read its page and verify every source link still
resolves. A reference that does not resolve is a bug in the same change.

A page that names a security gap is not describing the system. It is filing a
bug it forgot to file. The sentence and the issue land in the same commit.

No subsystems are documented yet. The first one is written when the first
subsystem has a behavior an agent would otherwise re-derive wrong. Until
then, do not invent a page to look complete.
